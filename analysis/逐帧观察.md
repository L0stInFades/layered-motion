## 下拉浮窗进入

1. **#80 / 0.900 s**：桌面基本清晰，控制卡片尚未显现。
2. **#83–86 / 0.934–0.967 s**：桌面已经缩小和模糊，顶部日期/状态先显现；大部分卡片仍非常透明。
3. **#87–93 / 0.978–1.045 s**：卡片开始出现。可见边界由较小的右侧区域向最终位置展开，尺寸、位置、材质不透明度同时变化。音量和亮度白色填充比玻璃暗部更容易先看见；这不等于能证明系统给它们设置了独立延迟。
4. **#94–107 / 1.056–1.200 s**：卡片继续变大，间距趋于稳定；背景已接近最终模糊状态，前景仍在缓慢归位。
5. **#108–116 / 1.211–1.301 s**：仍有小幅位置和尺寸收敛，随后基本稳定。

可见行为支持「位置 + 缩放 + 透明度 + 独立背景」的组合。没有足够证据断言用了真正的三维透视、液体折射或某个具体动画库。

## 下拉浮窗退出

1. **#134–135 / 1.501–1.512 s**：处于展开状态。
2. **#136–140 / 1.523–1.567 s**：卡片上移、缩小和透明化。单个圆形按钮的尺寸明显收缩，而按钮中心间距变化更少。桌面开始恢复。
3. **#141–145 / 1.578–1.622 s**：大部分浮层已不可见，桌面仍有残余模糊与缩放。
4. **#146–156 / 1.633–1.744 s**：背景继续恢复清晰和原始大小。

**退出不是进入的时间反转。**进入时各层沿自己的轨迹展开和收稳，退出时按钮自身缩放、中心布局收拢、上移及淡出分别推进。复刻使用每个前景元素独立的 X、Y、缩放状态；切换目标时保留各自当前位置和速度。

## 负一屏进入

1. **#339–342 / 3.779–3.812 s**：背景先开始缩小和模糊，卡片主体尚未进入。
2. **#345 / 3.845 s**：左边缘开始露出卡片。
3. **#346–355 / 3.856–3.957 s**：各层从左侧滑入，搜索栏领先，快递卡、快捷图标、照片卡与底部应用逐层跟上。快递卡顶部、底部高度基本保持；横向位移不可用一张卡片代表整组。
4. **#359–363 / 4.002–4.046 s**：横向位置进入尾部收敛。白色快递卡片左边缘约由 66 px 到 76 px，最终约 78 px。
5. **#371 / 4.135 s**：稳定画面。快递卡片白色区域约为 x=78、y=188、宽=424、高=196（1182×836 坐标系）。

这里的主要前景动作是**尺寸基本固定、分层错时的横移**。4.024 秒快递卡只剩约 7.5 px，而底部应用仍剩约 72 px。背景独立缩放、模糊；同一卡片内已测图标、文字保持相对位置。

## 不能从这些帧证明的事

- 真实手指轨迹、按下/松手时间和输入速度；录屏未显示完整触摸事件。
- 原系统内部究竟是贝塞尔曲线、弹簧还是分段曲线。网页使用可保留速度的弹簧，是为复现观察到的连续性。
- 单一颜色/模糊参数等于原系统参数。报告中的数值是对输出像素的近似拟合。
