# 层序动效规范 v0.1

状态：公开研究规范 · 版本：0.1.0 · 适用对象：浮动面板、控制中心、侧向信息页。

本规范把一套录屏中的空间关系与时序整理成可复用的设计约束。目标是**及时响应、层次清晰、收尾克制、随时可打断**。中文为本版本的规范文本。

## 1. 规范的边界

**必须 / MUST** 是采用本规范时的行为要求；**建议 / SHOULD** 可根据交互语义调整，但应写明理由；**参考 / REFERENCE** 只描述本次录屏或演示实现。

本规范不规定所有面板都延迟相同毫秒数，也不要求复制系统图标、照片或配色。录屏没有触摸事件，不能唯一恢复系统的物理参数、手势曲线或渲染架构。

适用：用户触发的面板展开、边缘滑入、信息层级切换。不适合直接套用到紧急提示、连续高频数据更新或需要即时定位的精密操作；这些场景首先保证可读和可控。

## 2. 分组：先确定什么一起动

| 层级 | 职责 | 必须保持的关系 |
|---|---|---|
| 背景层 | 交代原位置，降低旧内容的视觉权重 | 使用独立通道；与前景共用同一状态目标 |
| 面板 / 卡片层 | 承载语义单元 | 图标、文字、底板的稳定相对关系 |
| 控件层 | 表达按钮或滑块的独立形体 | 中心位移与自身尺寸分别建模 |
| 装饰层 | 提供光感、轮廓和反馈 | 不承担关键信息的唯一表达 |

**LM-01 必须按语义分组。** 同一按钮的图案与标签、同一卡片的正文与底板，默认共同运动。只有明确表达状态变化时，才新增内部动画。不能因为 DOM 中有多个子节点就逐个错峰。

原片依据：以快递卡底板对齐后，内部文字和图标基本稳定；同排四个快捷图标的横移差约 0–0.5 px。搜索、快递、快捷图标、照片、底部应用则形成五个独立运动层。[逐特征证据](../analysis/图标时序复查.md)

## 3. 时序：有先后，也要重叠

**LM-02 建议沿阅读或操作方向组织层次。** 优先操作区域先变得稳定，其余内容随之收稳。层与层的过程应有重叠，避免用户等待逐项播放完毕。

**LM-03 必须分别考虑启动与收尾。** 只给同一条曲线添加 `index × delay` 不能表达不同层的收敛。至少审查启动时机、主要行程、尾段这三个阶段。对于本参考负一屏，搜索 → 快递 → 快捷图标 → 照片 → 应用依次收稳。

**LM-04 建议让细微回收发生在尾段。** 大行程应明确、迅速；终点附近允许少量回收。是否越过终点取决于语义与空间，不能给所有层添加相同弹跳。静止目标不得持续振荡。

参考观测，1182 × 836 坐标，数字为距稳定位置的 X 差：

| 原片 PTS | 搜索 | 快递 | 快捷图标 | 照片 | 应用 |
|---|---:|---:|---:|---:|---:|
| 3.935 s | −44 | −69.5 | −106 | −163.5 | −270.5 |
| 3.980 s | −15.5 | −25.5 | −43.5 | −76 | −143 |
| 4.024 s | −4.5 | −7.5 | −16 | −33 | −72 |
| 4.068 s | 0 | −0.5 | −3.5 | −10.5 | −29 |
| 4.112 s | +0.5 | +0.5 | −0.5 | −3.5 | −12 |

这些是画面测量，不是要求所有界面复用的时长。末尾的半像素差不应被解释成确定的物理机制。

## 4. 空间：位置、尺寸、材质各自负责

**LM-05 必须保留独立几何通道。** 当按钮尺寸变化与中心间距变化不同，应分别驱动控件的 `translate` 与自身 `scale`，避免通过父网格缩放把两者绑定。

原片参考：控制中心退出到 1.556 s，按钮图案尺度约 0.79，中心间距约 0.92。缩小更多的是控件自身，留白比例随之增加。

**LM-06 建议让背景独立退后。** 背景的缩放、模糊与色调变化应服务于注意力转移，并保留位置关联。参数从内容可读性与设备性能出发选择。不得让背景变化造成前景文字对比不足。

参考稳定值：控制中心桌面缩放约 0.933，负一屏约 0.849；这些是本录屏输出像素的拟合值，不能照搬为所有设备的缩放规范。玻璃材质应有足够的不透明底色作为不支持滤镜时的后备样式。

## 5. 生命周期：进入与退出分别设计

**LM-07 必须为进入与退出分别定义目标与时序。** 进入建立可阅读的秩序，退出释放当前工作区域。允许它们采用不同参数；不得以倒放进入动画代替退出设计审查。

参考负一屏：退出初段五层位移接近，之后下层移动更快。参考控制中心：退出时控件直径和中心布局按不同幅度收拢。

**LM-08 必须支持中途改向。** 已可见的运动层在改目标时保留当前的位置与速度，取消旧方向尚未生效的等待。只有明确不可见的初始化状态、用户要求的时间轴跳转或减少动态效果模式可以直接重置状态。

**LM-09 必须区分直接操纵与松手收敛。** 拖动时输入负责主要目标；跟随层可以有受控滞后。松手从当前渲染状态继续，不能从预设首帧重播。没有触摸记录的参考片，只能用于检查可见路径，不能用来证明真实跟手延迟。

推荐状态关系：

```text
closed → entering → open → exiting → closed
           ↕                 ↕
        dragging ←→ retargeting

每个层保存 position / velocity / target / pendingDelay
反向：保留前两者，更新 target，取消过时 pendingDelay
```

## 6. 时间与可访问性

**LM-10 必须以实际时间推进。** 时间单位明确为秒或毫秒，不能每帧固定加进度。刷新率变化不应改变总运动速度。暂停检查器时，所有可见通道也必须暂停。

**LM-11 必须提供减少动态效果路径。** 尊重 `prefers-reduced-motion` 或平台对应设置，立即到达稳定状态并清除延迟；信息、操作和当前状态仍然可用。若另选轻量淡入，必须在采用方验收中说明。

**LM-12 必须提供等价的非手势操作。** 打开、关闭和核心控件须可由按钮 / 键盘触发。不可见层不能遮挡输入或使键盘焦点落入不可见内容；关闭后焦点应有合理去处。模态场景另按平台的模态焦点规则处理。

## 7. 尺度、参数与性能

空间量应以组件或画布坐标表达，映射到显示尺寸时统一换算；比例量保持无单位。每个 spring 通道记录 `stiffness`、`damping` 和单位质量约定，或使用等价且连续的运动系统。

[参考预设](../tokens/layered-motion.json) 给出本实验的五层进入/退出参数与测量锚点。它们是 **REFERENCE**；LM-01 至 LM-12 的关系与行为才是规范主体。

建议优先变更位移、缩放、透明度。模糊成本需在目标设备上实测。性能验收记录设备、浏览器、视口、刷新率、帧间隔分布；不把某台机器上的结果当作跨设备保证。

## 8. 如何声明采用

采用方应提供：语义分层表、进入/退出的参数或曲线、反向与拖动测试、减少动态效果路径，以及至少一种目标设备的性能记录。使用 [验收清单](acceptance.md) 逐项说明通过范围和偏离理由。

实验室是可操作的研究参考。其应用内容和部分图形经过简化；未覆盖的生产可访问性与设备适配工作不能用轨迹拟合分数替代。
