# 为什么这套动画显得优雅

核心是**运动有层级，收尾有余量**。动作传达出轻重、远近和先后，同时保持内容的可读秩序。以下审美解释基于逐帧观测，是设计判断，不是用户感知实验的结论。

## 先后关系让视线有路可走

负一屏从搜索栏到下方应用依次收稳。3.935 s，搜索栏距终点只有 44 px，底部应用还差 270.5 px。上方已经接近可用，下方仍在跟进，眼睛可以顺着信息层级向下看。

各层运动在时间上重叠，因此仍被感知成一次完整的展开。这里的分寸在于：有次序，却没有逐个等候的拖沓。

## 内部稳定，让细节丰富而不纷乱

同一卡片里的图案和文字基本共同运动；需要区别的是卡片、图标行、照片等语义组。大组织关系变化，小组织关系稳定，用户始终认得这是同一个内容单元。

因此，精细的动画编排往往意味着有选择地让一部分内容保持同步。逐帧证据不支持给每条图标笔画额外添加延迟。

## 大位移果断，最后几像素放轻

控制中心快捷按钮大部分行程很快完成，终点附近还有少量越过与回收。第一排按钮在 1.278 s 的 Y 坐标约为 714、716.5、718、719 px，最终约为 714–715 px。

这几像素让停止变得柔和，产生轻微的重量感。幅度足够小，视觉注意力仍停留在控件的功能上。负一屏下层较长的尾段也形成类似的舒展感。

## 控件缩小，空间仍然舒展

控制中心退出时，按钮图案缩至约 79%，中心间距仍保留约 92%。控件与周围留白的比例发生变化，画面显得更轻、更透气。

它还保留了每个按钮独立的形体感。若把整个父网格统一缩放，留白和控件一起收缩，就会损失这层细节。

## 背景配合，注意力自然交接

前景展开时，桌面缩小、模糊、调整色调。背景仍在原处，但视觉权重下降；前景的玻璃材质又保留了一部分联系。新内容因此有“浮到前面”的空间感。

这里的模糊服务于层次：它与缩放、颜色、前景清晰度共同工作。只增加模糊强度，并不能独立获得同样的效果。

## 进入有展开感，退出有利落感

进入时让信息逐层可读；退出时释放空间。负一屏退出初段几层近乎同移，之后下层离开更快。两个方向承担不同任务，节奏也不同。

进一步用于可交互产品时，反向打断需要连续地承接当前位置和速度。流畅的观感只有在用户随时改变主意时仍然成立，才会成为稳定的操作手感。

由这些观察提炼的设计原则是：**语义组内稳定，组间有序；大动作明确，小尾段克制；背景与前景共同完成注意力转移。**
